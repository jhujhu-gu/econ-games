課前準備與道具清單

  • ✓
    核心道具： 準備 1~2 副撲克牌，只取數字 1 ~ 10（A 代表 1）。
  • ⚠️
    🔥 核心趣味守則：絕對不能亮出底牌！

    遊戲中絕對不能讓別人看到自己的牌！真實商戰中沒人會把底牌直接秀給人家看。只有保持資訊不對稱，才有虛張聲勢、大膽喊價與相互議價的極致樂趣！

  • ✓
    角色與底牌規則： 將全班拆為「買賣兩大陣營」自由交易：
    🔴 買方 (Buyer) 抽紅色牌（心、方）

    牌面數字 = 最高願意支付價格 (WTP)

    🔵 賣方 (Seller) 抽黑色牌（梅、桃）

    牌面數字 = 最低願意接受價格 (WTA)

  • ✓
    勝負與平時成績：

    每次成交後向教師登記。獲取的「剩餘」就是平時分數：

    買方利潤 (消費者剩餘) 底牌 − 成交價
    賣方利潤 (生產者剩餘) 成交價 − 底牌

    ⚠️ 註：若成交價對自己不利（例如買方買貴、賣方賤賣）或未成交，該局得 0 分。

💡

核心教學提煉 (收網公式)

當市場上沒有任何人想改變交易決策時，即為「市場均衡」：

$$Q_d = Q_s$$ ( 需求量 = 供給量，此時達到市場均衡 )
👨‍🏫 教師引導提問 1： 「各位同學，遊戲中老師沒有設定交易價格，為什麼大家的成交價到最後，自發性地都擠在特定區間呢？」

👉 這就是亞當斯密著名的「看不見的手」(Invisible Hand)。透過價格機能驅使供需相等，自動調整達到平衡。

👨‍🏫 教師引導提問 2： 「那為什麼有些人自始至終都無法完成交易呢？是誰被排擠在市場之外了？」

👉 因為買方的最高願意支付價格（牌面數字）太低，或賣方的最低願意接受價格（牌面數字）太高，與市場均衡價格脫節，因而陷入「有價無市」的窘境而無法成交。這能讓學生明白，當個人的預期價格偏離市場行情時，就會被排除在市場交易之外。
